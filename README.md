# Tichi QA Internship Assignment

This repository contains the completed QA Intern Technical Assignment for the **Tichi** web application.

## Objective

Evaluate basic understanding of software testing and analytical thinking through test case creation and defect reporting for the Tichi application's Login and Signup functionality.

## Application Under Test

- **URL:** https://tichi-app-webapp-stage.web.app
- **Environment:** Staging
- **Modules Covered:** Login, Signup

## Task Breakdown

**Task 1 — Test Case Creation**
Test cases for Login and Signup pages, covering positive flows, negative flows, boundary/edge cases, and security input validation.

**Task 2 — Defect Reporting**
Defect report (DR-001) documenting the invalid-email-login issue, including steps to reproduce, expected vs. actual results, severity/priority, impact, and suggested fix.

**Task 3 — Automation**
Not attempted (optional task).
